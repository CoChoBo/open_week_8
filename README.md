## 포트폴리오용 개인 기여 정리 (최다온)

이 프로젝트는 오픈소스SW 수업에서 공공 교육 데이터를 정리/요약하는 과제로 진행했습니다.

- KESS, 대학알리미에서 관련 통계 데이터 탐색
- 학과/학기별 주요 수치를 선별해 표 형태로 정리
- README에 데이터 출처 링크와 핵심 지표를 한 화면에서 볼 수 있게 구성
- 수업 발표/공유 시 바로 설명할 수 있도록 문서 흐름 정리

### 배운 점
- 공공 데이터는 출처별 지표 기준이 달라서, 비교 가능한 형태로 정리하는 과정이 중요하다는 점을 배웠습니다.
- 코드 구현뿐 아니라, 데이터를 읽기 쉽게 문서화하는 것도 프로젝트 전달력에 큰 영향을 준다는 점을 경험했습니다.
